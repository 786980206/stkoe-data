Splayed V2.1 统一对象式接口调用链图谱

四层纯对偶接口对齐：Table(Reader/Writer) > Dataset(Reader/Writer) > Index(Reader/Writer) > Field(Reader/Writer)
Table (Reader/Writer) Dataset (Reader/Writer) Index (Reader/Writer) Field (Reader/Writer)
1. 数据写入调用链 (.write)
TableWriter.write(data)
// 获得 .lock 互斥锁，解析分区与行计划
[新分区不存在] → DatasetWriter.init(part_path, sub_data) // 自动初始化新分区
[新列不存在] → DatasetWriter.create_field(name, dt, init) // 跨分区自愈建列 (未覆盖置NULL)
按 max_parallelism 切分 P_part × P_field 并发调度
DatasetWriter.write(offset, sliced_view)
// 校验行限，按列并发分发至各个 FieldWriter
逐列下推 (std::thread::scope)
FieldWriter.write(offset, col_view)
// MmapMut 切片原地覆写 + copy_bits_into 批量更新 Validity 位
[若为 Header-Only 延迟骨架] → 自动触发物理空间就地展开并重新 MmapMut
2. 查询与扫描调用链 (.scan & .read)
TableReader.scan(request)
// 分区目录名二分剪枝 (零 META I/O)，产出 TableScanner
TableScanner.next() [惰性迭代命中分区]
DatasetReader.scan(request)
// 产出 DatasetScanner，协调索引定位与谓词计算
第一阶段: 索引定位
IndexReader.scan(request)
// 12B SYM INDEX 二分 → TIME AXIS 二分 → 输出 [row_start, row_start + count)
第二阶段: 逐谓词求值 (Predicate Pushdown)
FieldReader.scan(request)
// 向量化计算位图，与 Index 行区间求交集
第三阶段: 投影列提取 (Projection)
FieldReader.read(offset, length)
// Zero-Copy 零拷贝：直接从 Mmap 虚拟内存切片返回 ColumnView
3. DDL 结构变更与自愈修复 (.init_field & .fix)
TableWriter.init_field(name, dt)
// 仅在自然排序的最新分区新增单列结构 (免传 rows)
提取最新分区 latest_rows = dataset_reader.row_count()
FieldWriter.init_empty(path, dt, latest_rows)
// 物理写入 64B Header-Only 延迟骨架 (磁盘数据页分配为 0)
TableWriter.fix()
// 表存储完整性自愈入口
自底向上清理分区空目录后，扫描历史独有字段 (prior - latest)
[发现缺失字段] → FieldWriter.init_empty(latest_part_path, dt, latest_rows) // 最新分区补齐全空骨架，恢复全表 Schema 一致
[字段已对齐] // 刷新元数据，自愈完成
4. 四层纯对象式读写对称接口一览
层级 只读对象 (*Reader) 可写对象 (*Writer) 核心统一定义接口
Table TableReader TableWriter .scan() / .read() / .write() / .update() / .init_field() / .fix()
Dataset DatasetReader DatasetWriter .scan() / .read() / .write() / .update() / .create_field() / .locate()
Index IndexReader IndexWriter .scan() / .read() / .write() / .update() / .locate()
Field FieldReader FieldWriter .scan() / .read() / .write() / .update() / .init_empty()
